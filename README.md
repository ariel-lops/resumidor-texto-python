\# 📝 Resumidor de Texto em Python



Projeto simples desenvolvido em Python para gerar resumos de textos automaticamente.



---



\## 🚀 Como executar



1\. Certifique-se de ter o Python instalado.

2\. No terminal, navegue até a pasta do projeto.

3\. Execute:



python Resumidor-texto.py



---



\## 📌 Funcionalidades



\- Processamento de texto

\- Geração automática de resumo

\- Execução via terminal



---



\## 🛠 Tecnologias utilizadas



\- Python 3
